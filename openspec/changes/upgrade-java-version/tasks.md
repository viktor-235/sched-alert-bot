# Tasks

## 1. Choose the target version

- [ ] 1.1 Find the latest GA Java feature release and its LTS status; confirm `eclipse-temurin:<N>-jre` and the Temurin JDK exist for linux/amd64 and linux/arm64/v8 (`docker buildx imagetools inspect eclipse-temurin:<N>-jre`). Fall back to the previous version per design.md if not. Verify: target version noted, to go into the commit/PR body.
- [ ] 1.2 Check compatibility of Gradle, Spring Boot, Lombok, MapStruct, Testcontainers and Mockito/Byte Buddy with the target from their release notes/compatibility matrices. Verify: list of required version bumps noted.

## 2. Build tooling

- [ ] 2.1 Upgrade the Gradle wrapper if required (`./gradlew wrapper --gradle-version <v>` twice, so the wrapper files are regenerated by the new version). Verify: `./gradlew --version` shows the new version and the build still passes on Java 21.
- [ ] 2.2 Add `.java-version` with the target major version and make the `build.gradle` toolchain read it. Verify: `./gradlew -q javaToolchains` lists the target and `./gradlew compileJava` uses it.
- [ ] 2.3 Bump Spring Boot / Lombok / other libraries identified in 1.2. Verify: `./gradlew test` passes locally on the target JDK.

## 3. CI and image

- [ ] 3.1 Switch `ci.yml` and `release.yml` `actions/setup-java` from `java-version: '21'` to `java-version-file: .java-version`. Verify: CI on the commit is green and its "Setup Java" step logs the target version.
- [ ] 3.2 Update `Dockerfile` to `eclipse-temurin:<N>-jre`. Verify: `docker build` succeeds and `docker run --rm --entrypoint java <image> -version` prints the version from `.java-version`; the app starts locally via `docker compose up app-local-build` (Mongock runs, `/actuator/health` UP).

## 4. Docs and final check

- [ ] 4.1 State the required Java version (from `.java-version`) in the README prerequisites. Verify: README renders and matches `.java-version`.
- [ ] 4.2 Run `./gradlew test`. Verify: all tests pass, including the event lifecycle integration tests (new, changed, live, finished, canceled, returned after cancel).

## Workflow follow-up

- Release an RC and check it on the test stand (`CONTRIBUTING.md` §9) before the stable tag.
- Archive the change before merge.
